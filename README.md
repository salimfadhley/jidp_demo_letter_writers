# jido_demo1

Experiments with [Jido](https://hexdocs.pm/jido), the Elixir multi-agent framework. Each demo is a self-contained Mix project in its own top-level directory.

| Demo | What it is |
| --- | --- |
| [`letters1/`](letters1/README.md) | *The Etheridge Circle, 1891*: four agents, each a character in a late-Victorian epistolary drama, write letters to one another through OpenRouter. Private state per agent, structured letters, a curated almanac of 1891 events, and a director that follows the characters' own decisions. |

| [`play1/`](play1/README.md) | *An Evening at Mrs. Ashworth's*: the same characters in one drawing-room, each playing a UCB-style "game", taking beats of dialogue and action; output as a screenplay. |

To work on a demo, `cd` into its directory and follow its README.
